# Privacy Policy for ChatGPT Read Aloud with Controls

Last updated: 14/08/2025

## Overview

ChatGPT Read Aloud with Controls is a browser extension that enhances ChatGPT's read-aloud feature with professional audio controls. This extension is committed to protecting user privacy and does not collect, store, or transmit any personal information.

## Data Collection

This extension:

- Does not collect any user data
- Does not store any information locally or remotely
- Does not make any external network requests beyond intercepting ChatGPT's audio
- Does not use cookies or any tracking mechanisms
- Only processes audio streams from ChatGPT to provide enhanced controls

## Data Usage

The extension only processes audio streams that are already being generated by ChatGPT to provide enhanced playback controls. This processing:

- Occurs entirely within your browser
- Is temporary (only while audio is playing)
- Is never transmitted anywhere
- Is never stored

## Permissions

This extension requires minimal permissions:

- `webRequest`: Required to intercept and enhance ChatGPT's audio streams
- `https://chatgpt.com/*`: Required to run on ChatGPT pages and detect read-aloud functionality

These permissions are used solely to provide the core functionality of enhanced audio controls for ChatGPT's read-aloud feature.
