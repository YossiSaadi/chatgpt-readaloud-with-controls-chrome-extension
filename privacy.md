# Privacy Policy for ChatGPT Read Aloud with Controls

Last updated: 10/09/2026

## Overview

ChatGPT Read Aloud with Controls is a browser extension that enhances ChatGPT's read-aloud feature with professional audio controls. This extension is committed to protecting user privacy and does not collect, store, or transmit any personal information.

## Data Collection

This extension:

- Does not collect any user data
- Does not transmit any information anywhere — there are no network requests to any server other than the audio requests ChatGPT itself makes
- Does not use cookies or any tracking mechanisms
- Only processes audio streams from ChatGPT to provide enhanced controls
- Stores exactly one piece of non-personal data in your browser's `localStorage`: the audio player's on-screen position and size (numeric values only), so the player stays where you placed it. This never leaves your browser and contains no conversation or personal data.

## Data Usage

The extension only processes audio streams that are already being generated by ChatGPT to provide enhanced playback controls. This processing:

- Occurs entirely within your browser
- Is temporary (only while audio is playing)
- Is never transmitted anywhere
- Is never stored

## Permissions

This extension requires a single permission:

- Host access to `https://chatgpt.com/*`: Required to run on ChatGPT pages, detect the read-aloud audio, and show the player controls

There are no other permissions — no background access, no browsing-history access, no access to any other website. The audio is captured by observing the request ChatGPT's own page makes for its read-aloud feature, entirely inside the ChatGPT tab.
